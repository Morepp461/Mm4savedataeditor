# MM4 Save Data Editor

Native Android application for inspecting and editing Motorsport Manager 4 career save files.

## Current foundation
- Android Storage Access Framework import/export; no broad storage permission.
- Reads the 24-byte little-endian container header observed in the supplied `SlotTwo.msv`.
- Decompresses the two independent LZ4 blocks (Save Info and Game Data) into JSON.
- Dynamic nested field browser with path/value search.
- Typed JSON value editing, including scalar values and replacement of existing nested object/array values.
- Re-encodes the two blocks and decodes the generated bytes again before export.
- Unknown fields and reference properties are retained in the JSON tree.

## Observed container profile
- Magic bits: `0x99131871`
- Container version: `40`
- Header: six little-endian Int32 values (24 bytes): magic, version, info compressed length, info plain length, data compressed length, data plain length.
- Payload: LZ4 info block followed by LZ4 game-data block.

This profile comes from one supplied save file. Other game versions may use a different profile. A successful codec round-trip does not prove that the game accepts every edited value.

## Build
The GitHub Actions workflow builds a debug APK in the cloud and uploads it as an artifact. It uses JDK 17 and Android SDK 35.

## Validation warning
Always edit a duplicate save. The project still needs a successful CI build, device QA, and in-game validation. It does not yet have semantic validation for every field, add/remove operations for arbitrary keys or array elements, or dedicated entity-specific editor screens.
